* Overview

Personal Emacs configuration for Emacs 30.x.

Uses ~use-package~ for most package management, with ~el-get~ (via
~el-get-bundle~) for select packages. The ~no-littering~ package keeps
data and cache files organized outside =~/.config/emacs/=.

* Structure

| File              | Purpose                                    |
|-------------------+--------------------------------------------|
| =init.el=         | Main configuration                         |
| =custom.el=       | Emacs customize settings (auto-generated)  |
| =early-init.el=   | Early initialization (before UI)           |
| =changes.org=     | Changelog of manual fixes and changes      |
| =tasks.org=       | Outstanding and completed tasks            |
| =status.org=      | Current configuration health status        |
| =insights.org=    | Technical notes and lessons learned         |

* Revision Control

Files are tracked with RCS. Revision history is stored in the =RCS/=
subdirectory. All tracked files carry the ~$Id: readme.org,v 1.3 2026/03/05 17:07:06 scs Exp $~ keyword, which RCS
expands to show filename, revision, date, and author.

Common commands:
- ~ci -l <file>~ — check in (keep locked for editing)
- ~co -l <file>~ — check out with lock
- ~rlog <file>~ — view revision history
- ~rcsdiff <file>~ — diff working file against last revision

* Key Packages

- *Completion:* corfu, cape, vertico, orderless, marginalia, consult
- *Org:* org-mode, denote, org-contrib (ob-ly, org-expiry)
- *Lisp:* slime, sly, paredit
- *UI:* hl-todo, delight, which-key
- *Files:* no-littering, recentf
- *Remote:* tramp
