* Document role

* Overview

Improvement ideas and candidate keybindings for ~scsets/config-emacs~.
Grounded in the current setup: Vertico minibuffer (Orderless + Consult
+ Embark), Company in-buffer, Hyper namespace on macOS (Karabiner Fn),
~C-c~ / ~C-c t~ / ~C-c .~ prefix maps, Org/howm/org-id notes, TRAMP via
~lisp/scs-tramp.el~.

Priorities: keep Hyper for macOS-only ergonomics; add ~C-c~ chords for
behaviour that must work on FreeBSD and SmartOS CLI too.

** macOS Hyper — new single keys

Bindings below are *macOS only* (~when (eq system-type 'darwin)~), same
guard as current Hyper block.

| Chord | Command                     | Mnemonic / rationale                          |
|-------+-----------------------------+-----------------------------------------------|
| ~H-m~ | ~imenu-list-smart-toggle~   | *m*ap — sidebar outline (~H-i~ is ~consult-imenu~) |
| ~H-f~ | ~fd-dired~                  | *f*ind files (fd); needs ~fd~ on PATH         |
| ~H-u~ | ~undo~                      | *u*ndo                                        |
| ~H-y~ | ~yank-pop~                  | *y*ank cycle (pairs with kill keys)           |
| ~H-/~ | ~howm-search~               | search ~/notes                                |
| ~H-e~ | ~howm-list-recent~          | r*e*cent notes (or ~howm-list-all~ if preferred) |
| ~H-D~ | ~dired~                     | *D*ired at default directory (capital = dir)  |
| ~H-T~ | ~scs/tramp-cleanup~         | move ~H-t~ cleanup here; free ~H-t~ for below   |
| ~H-t~ | ~scs/tramp-find-file~       | *t*ransfer / remote file (pairs with ~C-c t~*)  |

*Note:* ~H-t~ is currently ~my/tramp-cleanup~; if ~H-T~ feels awkward,
keep cleanup on ~C-c t c~ only and use ~H-t~ for find-file.

** Cross-platform ~C-c~ — new bindings

These should work on macOS CLI, FreeBSD, and SmartOS without Hyper.

| Chord       | Command                         | Rationale                               |
|-------------+---------------------------------+-----------------------------------------|
| ~C-c v n~   | ~diff-hl-next-hunk~             | *v*cs — next change                     |
| ~C-c v p~   | ~diff-hl-previous-hunk~         | previous change                         |
| ~C-c v s~   | ~diff-hl-show-hunk~             | show current hunk                       |
| ~C-c v r~   | ~diff-hl-revert-hunk~           | revert hunk (use with care)             |
| ~C-c g w~   | ~wgrep-enable~                  | *g*rep *w*rite mode in grep buffer      |
| ~C-c b~    | ~ibuffer~                       | buffer list (~list-buffers~ remapped)   |
| ~C-c j l~   | ~avy-goto-line~                 | *j*ump line (if ~C-c j~ stays char)     |
| ~C-c j w~   | ~avy-goto-word-or-subword-1~    | jump word                               |
| ~C-c n h~   | ~howm-create~                   | *n*ote *h*owm (mirror ~C-f9~)            |
| ~C-c n l~   | ~howm-list-all~                 | list notes (mirror ~F9~)                |
| ~C-c SPC~   | ~consult-mark~         | mark jumps — *if* a dedicated chord is wanted |

Define ~C-c v~ as a small prefix map (~define-prefix-command~), same
style as ~scs/quit-map~, not Hydra.

** ~C-c h~ is ~consult-history~

Do not grow a Helm-style prefix under ~C-c h~.  Resume the last Consult
search from the command itself; ripgrep is ~M-s r~.

* Implementation order (suggested)

1. ~diff-hl~ + ~wgrep~ keys (~C-c v~ / grep hook) — small, high value.
2. Extend ~H-c~ prefix (~t~, ~r~, ~n~) — org/howm workflow.
3. ~C-c b~ → ~ibuffer~ — cross-platform buffer menu.
4. CLI parity table in ~readme.org~ / ~insights.org~ for Hyper mirrors.
5. ~early-init~ GCC path robustness.
6. ~status.org~ / ~tasks.org~ housekeeping.

* Explicit non-goals

- *Hydra* for quit or small menus — current ~set-transient-map~ quit
  flow and prefix maps are enough (~readme.org~ / session 2026-07-08).
- *Replacing Vertico* with another minibuffer UI — Helm is gone;
  keep one stack.
- *Replacing el-get* — large migration; only revisit if bootstrap pain
  grows.
