* 2026-03-07 Howm: semantic filenames and directory change

- Changed ~howm-directory~ from =~/note= to =~/notes=.
- Added ~scs--howm-maybe-rename~: on save, computes desired filename
  from org heading title, ~#+filetags:~, and ISO date. Prompts with
  ~y-or-n-p~ before renaming; user can decline to keep the old name.
- Format: =my-note-title_tag1-tag2_2026-03-07.org=
- Won't rename if target file already exists.
- Helper ~scs--howm-slugify~ converts strings to lowercase hyphenated slugs.

* 2026-03-07 Add howm/org-node integration, fix Emacs server

- Removed ~server-use-tcp t~ for default server; now uses Unix domain sockets
  (works on macOS, FreeBSD, SmartOS). Added second TCP server named "scrim"
  for the Scrim macOS app via ~let~-bound ~server-name~ / ~server-use-tcp~.
- Enhanced howm configuration:
  - Org-mode template with ~#+filetags:~ line.
  - Increased menu/schedule visibility: 30 recent notes, 30-day lookahead.
  - Moved ~howm-keyword-file~ and ~howm-history-file~ into ~no-littering~ paths.
  - Added hooks: ~howm-mode-set-buffer-name~, ~(org-mode . howm-mode)~.
  - Enabled ~howm-view-split-horizontally~ and ~howm-view-contents-limit~.
- Added ~use-package org-node~ (from Baty's howm+org-node article):
  - ~(howm-create . org-node-nodeify-entry)~ hook auto-adds org IDs to new notes.
  - Populates ~org-id-extra-files~ from howm directory.

* 2026-03-07 Optimise startup (4s -> 0.6s)

- Removed ~use-package~ bootstrap (~package-install~) — built-in since Emacs 29.
- Fixed ~package-vc~ re-install loop: ~framemove~ and ~psvn~ with ~:vc :rev :newest~
  triggered ~package-refresh-contents~ and "Overwrite?" prompt on every startup.
  Now guarded with ~(unless (package-installed-p ...))~.
- Deferred heavy packages with idle timers:
  ~company~ and ~cape~ at 2s, ~flycheck~ at 3s, ~which-key~ and ~recentf~ at 1s.
- Changed ~org-babel~ from ~:demand t~ to ~:after org~ (loads only when org loads).
- Changed ~org-protocol~ from eager ~require~ to ~with-eval-after-load 'server~.
- Removed ~psvn~ — GitHub repo (emacsmirror/psvn) no longer exists.
  Using built-in ~vc-svn~ instead.
- Removed ~ob-ly~ — no longer included in org-contrib 0.8.
  Removed ~(ly . t)~ from ~org-babel-load-languages~.

* 2026-03-05 Clean up early-init.el and init.el

** Comment style standardization
- All section headers use ~;;;~ (top-level) and ~;;;;~ (subsection),
  following standard Emacs Lisp conventions and ~outline-minor-mode~.
- Regular comments use ~;;~, end-of-line annotations use ~;~.
- Replaced decorative separator lines (~======~, ~********~) with
  clean ~;;; ---~ where a visual break is warranted.

** early-init.el
- Renamed ~prot-emacs--~ variable prefix to ~scs--~ (personal config).
- Normalized spacing: single blank between items, double between sections.

** init.el -- section reordering
- Reordered into logical sections: Compatibility, Custom functions,
  Package managers, General settings, Custom file, Keybindings,
  Packages (alphabetical), Sample keymaps, Finalization.
- All commented-out code and annotation tags (~:gem:~, ~:vip:~, etc.)
  preserved in place.

** Formatting fixes
- Consistent 2-space indentation inside ~use-package~ blocks.
- Fixed leading space on ~(use-package company~ form.
- No trailing ~)~ on its own line in ~use-package~ blocks where possible.
- Single blank line between items, double between sections.
- Cleaned up timestamp lambda formatting.

  ~<f9>~ binding.

** What did NOT change
- No code removed; all commented-out blocks preserved.
- No semantic/behavioral changes; same guards, same settings.
- =custom.el= untouched.
- el-get bootstrap logic kept as-is.

* 2026-03-05 Cross-platform adaptation (macOS / FreeBSD / SmartOS)

** Guiding principle: CLI-first, no unnecessary dependencies
- GUI and macOS features are now opt-in via guards.
- On FreeBSD/SmartOS terminal, everything works with zero extra packages.

** early-init.el guards
- ~(tool-bar-mode -1)~ wrapped with ~(display-graphic-p)~.
- ~undecorated-round~ frame parameter wrapped with ~(eq window-system 'ns)~ (macOS GUI only).
- ~set-frame-name~ wrapped with ~(display-graphic-p)~.

** init.el — macOS-specific guards
- Mac modifier keys (~mac-command-modifier~, ~mac-option-modifier~,
  ~mac-control-modifier~, ~ns-function-modifier~) wrapped in ~(eq system-type 'darwin)~.
- ~exec-path-from-shell~ guarded with ~:if (eq system-type 'darwin)~.
- ~reveal-in-osx-finder~ guarded with ~:if (eq system-type 'darwin)~.
- ~server-use-tcp~ (for scrim macOS app) guarded with ~(eq system-type 'darwin)~.

** init.el — executable-find guards
- aspell settings wrapped in ~(executable-find "aspell")~.
- ugrep xref-search-program wrapped in ~(executable-find "ugrep")~.
- howm ripgrep settings wrapped in ~(executable-find "rg")~ with grep fallback.

** init.el — GUI-only guards
- ~pixel-scroll-precision-mode~ additionally guarded with ~(display-graphic-p)~.

** init.el — safe jar paths for org-babel
- ~org-plantuml-jar-path~ and ~org-ditaa-jar-path~ now guarded with
  ~(getenv "PROFILE_DIR")~ and ~file-exists-p~ checks.

** Housekeeping
- Moved =scs.org= to =attic/= (literate config not actively tangled).

* 2026-03-05 Fix Emacs 30 startup failure and clean up stale paths

** Blocking: el-get plist-put crash
- File: =el-get/el-get/el-get-bundle.el:92-94=
- Emacs 30 enforces strict type checking on ~plist-put~; passing a string
  (from ~(car spec)~) instead of a plist caused:
  ~wrong-type-argument plistp "impatient-mode"~
- Fix: initialize ~s~ as ~nil~ instead of ~(car spec)~.
- Deleted stale =el-get-bundle.elc= so the patched source takes effect.

** Unicode smart quote in init.el
- File: =init.el:741=
- A Unicode LEFT SINGLE QUOTATION MARK (U+2018) was used instead of ASCII
  apostrophe (U+0027) in a ~setq~ form, causing ~void-variable~.
- Also removed erroneous quoting of the variable name in ~setq~.

** Undefined function ~user-data~
- File: =init.el:1051=
- Replaced ~(user-data "tramp")~ with ~(no-littering-expand-var-file-name "tramp")~.

** Hardcoded user paths
- Files: =init.el:1014,1024= and =custom.el:11=
- Replaced ~/Users/priyadarshan/...~ with =~/...= and ~expand-file-name~
  for OS-independent home directory resolution.

** Consolidate org-contrib into use-package
- Removed duplicate ~:ensure org-contrib~ from the ~org~ use-package block.
- Replaced ~(el-get-bundle org-contrib)~ with a standalone ~use-package~
  block that requires ~ob-ly~ and ~org-expiry~ in its ~:config~.
- This eliminates the el-get / package.el load-order warning for org-contrib
  and ensures ~ob-ly~ is available for Org Babel LilyPond blocks.

** Add lexical-binding to init.el
- Added ~-*- lexical-binding: t -*-~ to the first line of =init.el=.

** Add RCS Id keywords
- Inserted the RCS Id keyword in =init.el=, =custom.el=, =changes.org=,
  =tasks.org=, =readme.org=, =status.org=, and =insights.org=.
- All files checked into RCS at revision 1.2.
