* 2026-03-05 Fix Emacs 30 startup failure and clean up stale paths

** Blocking: el-get plist-put crash
- File: =el-get/el-get/el-get-bundle.el:92-94=
- Emacs 30 enforces strict type checking on ~plist-put~; passing a string
  (from ~(car spec)~) instead of a plist caused:
  ~wrong-type-argument plistp "impatient-mode"~
- Fix: initialize ~s~ as ~nil~ instead of ~(car spec)~.
- Deleted stale =el-get-bundle.elc= so the patched source takes effect.

** Unicode smart quote in init.el
- File: =init.el:741=
- A Unicode LEFT SINGLE QUOTATION MARK (U+2018) was used instead of ASCII
  apostrophe (U+0027) in a ~setq~ form, causing ~void-variable~.
- Also removed erroneous quoting of the variable name in ~setq~.

** Undefined function ~user-data~
- File: =init.el:1051=
- Replaced ~(user-data "tramp")~ with ~(no-littering-expand-var-file-name "tramp")~.

** Hardcoded user paths
- Files: =init.el:1014,1024= and =custom.el:11=
- Replaced ~/Users/priyadarshan/...~ with =~/...= and ~expand-file-name~
  for OS-independent home directory resolution.

** Consolidate org-contrib into use-package
- Removed duplicate ~:ensure org-contrib~ from the ~org~ use-package block.
- Replaced ~(el-get-bundle org-contrib)~ with a standalone ~use-package~
  block that requires ~ob-ly~ and ~org-expiry~ in its ~:config~.
- This eliminates the el-get / package.el load-order warning for org-contrib
  and ensures ~ob-ly~ is available for Org Babel LilyPond blocks.

** Add lexical-binding to init.el
- Added ~-*- lexical-binding: t -*-~ to the first line of =init.el=.

** Add RCS Id keywords
- Inserted the RCS Id keyword in =init.el=, =custom.el=, =changes.org=,
  =tasks.org=, =readme.org=, =status.org=, and =insights.org=.
- All files checked into RCS at revision 1.2.

* 2026-03-05 Improve early-init.el

** Critical fix: restore file-name-handler-alist and vc-handled-backends
- =early-init.el= set both to ~nil~ for startup speed but the ~defvar~
  save and ~emacs-startup-hook~ restore were commented out.
- This permanently broke TRAMP, compressed file handling, and VC detection.
- Fix: uncommented save/restore; both are now properly restored after startup.

** Move settings from init.el to early-init.el
- ~native-comp-async-report-warnings-errors~, ~warning-minimum-level~,
  ~byte-compile-warnings~: suppress warnings before any compilation fires.
- ~package-native-compile~, ~package-archives~, ~package-initialize~:
  configure and initialize packages in early-init where they take effect
  earliest, replacing the old ~package-enable-at-startup nil~ pattern.
- ~(tool-bar-mode -1)~: prevent toolbar from drawing then hiding (flicker).

** Add lexical-binding and RCS Id to early-init.el
- Added ~-*- lexical-binding: t -*-~ and RCS Id keyword.

** Add user-emacs-directory for no-littering
- Set ~user-emacs-directory~ explicitly so paths are established before
  anything else runs.

** Updated scs.org
- Removed tangled code that was moved to early-init.el.
- Added notes explaining the relocation.
