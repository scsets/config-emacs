* Try in Emacs (after reload)

Reload config (=C-c r=) or restart Emacs, then:

| UI | Start | First moves |
|---+---|---|
| mu4e | =C-c m m= | =j g= global INBOX; list top / body bottom; =c= compose; =C-c C-c= send |
| notmuch | =C-c m n= or =C-c m s= | =RET= thread (opens below); =m= compose; =C-c C-c= send |
| compose (any) | =C-c m c= | pick From; Org body via =org-msg=; =C-c C-c= send |

*** Layout and threads

- mu4e :: =mu4e-split-view= horizontal; related messages on (=mu4e-search-include-related=)
- notmuch :: search stays on top; show opens in lower window; search lines are threads

*** Contacts

Use the mail UI's own address completion (mu4e / notmuch).  Shell
preview of addresses already seen in the vault:

#+begin_src shell
mu cfind --format=json -n 5 ''
mu cfind --format=plain -n 5 ''
#+end_src

*** Sending

Lab send path: *=msmtp=* + =~/.msmtprc= (SMTPS *=465=*), passwords via
=authinfo-pass= / =~/.authinfo=.  Template: =docs/msmtprc.mail-lab=.

Emacs picks the msmtp account with =-a <From-address>= (hook in
=scs/mail-lab-configure-send=).

Compose body: *=org-msg=* (Org -> multipart text/html).  Toggle off with
=M-x org-msg-mode= if you want plain message-mode temporarily.

If msmtp exits *76* (GnuTLS push error), fall back to
=bin/mail-lab-sendmail= (Python =ssl= on =:465=).

Shell smoke test:

#+begin_src shell
printf 'From: SCS <scs@scs.re>\nTo: YOU@example.com\nSubject: lab send test\n\nhello\n' \
  | msmtp -a scs@scs.re -t
#+end_src

Then in Emacs reload lab code and =C-c m c= -> =C-c C-c=.

After a terminal =mbsync -a=:

#+begin_src shell
mu index
notmuch new
#+end_src

In mu4e, =U= also runs =mbsync -a= (then mu reindexes via its server).
