* Goal

Implement ~scs/update-last-updated-on-save~ per
=docs/2026-07-23-update-last-updated-on-save-design.org=.

* Architecture

Dedicated module =lisp/scs-file-header.el= with a silent ~before-save-hook~
function. Org and Lisp families each have a preamble-end finder and a
field rewrite for the first matching timestamp line. Stamp format is
local ~YYYY-MM-DD Day HH:MM~. Tests let-bind
~scs/file-header-stamp-function~ for a fixed stamp.

* Global constraints

- Timestamp field only; never UPDATE / VERSION.
- No insert if missing; first preamble match only.
- Never signal an error that aborts save.
- Do not commit unless SCS asks (repo rule overrides plan commit steps).
