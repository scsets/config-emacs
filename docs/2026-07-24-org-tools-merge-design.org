* Summary

Make ~lisp/org-tools.el~ the single home for team Org helpers: export
(line-prefix, stationery, PDF/X) plus buffer tools currently in
~lisp/scs-org-tools.el~ (header ensure, creation-date, zwsp markers,
rename-at-point).  Delete ~scs-org-tools.el~.  Retarget every live load,
autoload, test, and ops doc so old ~require~/~autoload~ paths keep
working by pointing at ~org-tools~, not via a shim file.

* Goals

- One library: ~org-tools.el~ hosts all reusable Org tools in this tree.
- Keep existing ~scs/~ interactive command and helper names (no rename).
- Hard cutover: delete ~lisp/scs-org-tools.el~ (no ~provide~ shim).
- Fix callers: ~init.el~ autoloads and ~require~, ERT harness, operator
  docs (~readme.org~, ~status.org~, ~changelog.org~, ~insights.org~
  load tables).
- Teachable file header and Commentary for the merged module.

* Non-goals

- Do not move howm, org-id, capture-finalize, or S-f9 helpers out of
  ~init.el~.
- Do not rename ~scs/org-*~ symbols to ~org-tools-*~.
- Do not rewrite historical ~docs/2026-07-*-*.org~ plan/design files
  beyond this new design/plan pair (they remain historical records).
- Do not change ~scs_org-buffer-template.org~ content or location
  (still beside the library under ~lisp/~).

* Target state

| Piece | Role after merge |
|-------+------------------|
| ~lisp/org-tools.el~ | Export + buffer helpers; ~provide 'org-tools~ only |
| ~lisp/scs-org-tools.el~ | Deleted |

| ~init.el~ | Autoloads from ~"org-tools"~; single ~(require 'org-tools)~ |

* Architecture

** Module layout (~org-tools.el~)

1. File header + Commentary describing both export and buffer helpers.
2. Shared requires: ~org~, ~scs-cl~, ~subr-x~, ~thingatpt~ (thingatpt
   needed for rename-at-point).
3. Existing export sections unchanged in behavior (line-prefix,
   stationery, PDF/X).
4. New sections appended (or clearly marked) for buffer helpers moved
   from ~scs-org-tools.el~, preserving symbol names and docstrings
   (edit only load-path / verify commands that still mention
   ~scs-org-tools~).
5. ~(provide 'org-tools)~ once at the end.

** Load path cutover

- Autoload file name string ~"scs-org-tools"~ -> ~"org-tools"~ for:
  ~scs/org-insert-creation-date~, ~scs/org-append-zwsp-markers~,
  ~scs/org-ensure-buffer-header~, ~scs/rename-visited-file-to-name-at-point~.
- Drop ~(require 'scs-org-tools)~; keep ~(require 'org-tools)~ under
  ~with-eval-after-load 'org~.

** Tests

- Rename ~test/scs-org-tools-test.el~ to ~test/org-tools-test.el~
  (git mv or equivalent).
- Update Filename / Description / Commentary batch command to load
  ~lisp/org-tools.el~.
- Keep ERT test symbol names that mirror commands (~scs/org-...~).
- Optional: leave a short note in Change Log that the suite moved from
  ~scs-org-tools-test~.

** Docs

Update live references in ~readme.org~, ~status.org~, ~changelog.org~
(and ~CHANGELOG.org~ if still mirrored), and the ~insights.org~ library
table / load examples.  Record the merge in ~changelog.org~ (GreyBeard
style).

* Risks and mitigations

| Risk | Mitigation |
|------|------------|
| Stale ~autoload~ still points at deleted file | Grep for ~scs-org-tools~ after edit; fix every live caller |
| Byte-compiled ~scs-org-tools.elc~ left behind | Delete ~.elc~ if present; gitignore already covers ~.elc~ |
| Template path breaks | ~scs/org-buffer-header-template-file~ still resolves relative to ~org-tools.el~ directory; keep ~scs_org-buffer-template.org~ in ~lisp/~ |
| ERT fails after move | Run batch ERT before claiming done |
