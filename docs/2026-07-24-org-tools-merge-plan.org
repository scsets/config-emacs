* Goal

Move all code from ~lisp/scs-org-tools.el~ into ~lisp/org-tools.el~,
delete the old library, retarget loads/tests/docs, keep ~scs/~ command
names, leave ~init.el~ howm/org-id helpers alone.

* Architecture

Append buffer-helper sections to ~org-tools.el~ (headers, creation-date,
zwsp, rename).  Rewrite Commentary so the file is the Org tools home.
Hard cutover of ~autoload~ / ~require~ / ERT / ops docs to ~org-tools~.

* Global constraints

- Emacs 29.1+, Org 9+ (existing Package-Requires).
- Keep symbol names (~scs/org-ensure-buffer-header~, etc.).
- ASCII only in edits.
- Prefer Org for docs; update ~changelog.org~ (hardlink of ~CHANGELOG.org~).
- Historical ~docs/2026-07-*-*.org~ plans stay as historical records.
