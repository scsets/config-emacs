* Goal

Ship ~scs/rename-visited-file-to-name-at-point~ per

binding ~H-c R~.

* Architecture

Helpers in ~lisp/scs-org-tools.el~ extract a basename at point, then the
interactive command confirms, optionally confirms overwrite, renames on
disk, and updates the visited file name. Autoload and bind from
~init.el~. ERT covers name extraction only (temp buffers; no live
rename required for extraction tests). Optional temp-dir ERT for the
full rename path if cheap.

* Tech stack

Emacs Lisp 29+, Org element API when available, ~thingatpt~.

* Global constraints

- ASCII only.
- Confirm then replace (no silent overwrite; no backup).
- Same directory only.
- No auto header keyword updates.
